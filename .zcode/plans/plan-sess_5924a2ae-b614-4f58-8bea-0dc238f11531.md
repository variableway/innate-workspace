# Model Market 目录功能（lobehub 市场数据接入）

## 架构结论（回答"需要 SDK 吗 / autorouter"）

- **不需要 SDK**：`internal/httpcheck` 已用纯 HTTP 实现三种协议的真实调用（anthropic / openai_responses / openai_chat），`test provider` 就是一次真实推理。运行时验证复用它。
- **claude code / codex 没有自动路由**（单协议单端点，正是 aiswitcher 存在的意义）；**opencode 原生支持多厂商**。网关型厂商（higress/aihubmix/openrouter）本身就是 autorouter，lobehub 数据的 `providers` 字段标注了每个模型可用的网关。
- **本地网关代理**（aisw 自己按模型名路由的反向代理）为后续独立里程碑，本次不做。

## 后端

**1. 新包 `internal/market`（纯客户端，不含存储）**
- `Client{http.Client, BaseURL}`，默认 `https://app.lobehub.com/trpc/lambda`，30s 超时、context 贯穿（沿用 httpcheck 模式）。
- `FetchCategories(ctx)`、`FetchModelsPage(ctx, {page,pageSize,category,q,locale})` 解码 tRPC 包装 `[0].result.data.json`；`FetchAll(ctx)` 循环 pageSize=100 拉全量（约 11 页，页间 200ms）。
- `Model` 类型镜像 lobehub 字段：identifier/displayName/providerId/providers/contextWindowTokens/abilities/pricing/category/source/enabled。

**2. 存储（按配置执行）**
- **SQLite**：新迁移 `migrations/<now>_market_models.go`（沿用 1780993000 模式）建 `market_models` 集合：identifier（唯一索引）、display_name、category、provider_id、providers(JSON)、context_window_tokens、enabled、raw(JSON)，allowPublicRead。`internal/store` 新增：`ReplaceMarketModels`（事务内全量替换）、`ListMarketModels(category,q)`。
- **文件**：`internal/market/filestore.go` 写 `~/.innate-aiswitcher/market/models.json`（env `AISW_MARKET_DIR` 覆盖，`safefile.Write` 0o600），schema 与已保存的 lobehub-model-market.json 一致。
- **配置**：启用闲置的 `settings` KV 集合，`store.GetSetting/SetSetting`；market 设置 `{storage: "sqlite"|"file"|"both"（默认 sqlite）, source_url, locale}`。

**3. REST 路由（app.go 新增 registerMarketRoutes，两种入口共用，无新 CLI 命令）**
- `POST /api/aisw/market/fetch` — 服务端拉全量 → 按配置写入 → `{ok, fetched, categories, storages, fetchedAt}`
- `GET /api/aisw/market/models?category=&q=` / `GET /api/aisw/market/categories` — 从配置的存储读取
- `GET/PUT /api/aisw/market/settings`
- `POST /api/aisw/market/import` — `{provider, models[]}` → 新增 `Store.AddModels` 批量方法（一次读 + 追加 + 单次 UpsertProvider）→ 返回脱敏 Provider。**API key 共享由现有机制自动保证**（key 在 provider 行上，syncProviderAPIKey 维护）。

## 前端

- `web/src/pages/market.tsx`：providers 页骨架（header + 状态分支）；header 放"拉取目录"按钮（spinner + toast 汇总）、存储后端徽标 + fetchedAt、设置对话框（storage 单选）；过滤行（分类 Select + 搜索框）；Table 列出模型（复选多选、identifier、displayName、providers 徽标、上下文窗口、abilities 徽标）；导入对话框（目标 provider Select + 提交，参照 preset-import 模式）。
- `api.ts` 加 6 个函数与类型；`queries.ts` 加 market key 与 hooks（import 成功后 invalidate providers）；`i18n.tsx` 加 `nav.market` + `market.*` 中英文案；`routes.tsx` + `app-shell.tsx` 注册 `/market` 路由与侧边栏项。
