# T02 — 首个真实 app 验收

> Sprint 4 ｜ 状态：todo ｜ 依赖：T01

## 步骤

1. 选一个真实需求的小 app（候选：innate-apps 里 backlog 的 keepthem 或新想法），用 factory 生成
2. 全链路：生成 → 本地 dev → 构建 → registry 登记 → GitHub issue 建立（看板第一张卡）→ 可选部署（cloudflare 项目）
3. 复盘：模板缺什么、生成器哪里别扭、skill 够不够用——反馈回 Sprint 3 模板迭代（回流）

## 验收

真实 app 上线/可运行；复盘清单写入本文件执行记录；模板与生成器各至少一次修正闭环。
