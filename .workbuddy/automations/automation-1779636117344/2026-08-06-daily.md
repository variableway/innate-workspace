## 1. Meta 发布首款 AI 编程智能体 Muse Code，以价格战杀入赛道

**类别：AI Coding**

Meta 今日正式推出首款终端编程智能体 Muse Code，搭载自研模型 Muse Spark 1.2，由超级智能实验室负责人 Alexandr Wang 主导发布，扎克伯格亲自在 X 官宣。产品对标 Claude Code 和 OpenAI Codex，一条命令安装即可承担规划变更、编写代码、验证结果的全流程软件工程任务。

- **跑分表现**：Terminal Bench 2.1 达 82.9%，优于 Codex 的 81.8%，但低于 Claude Code 的 86.7%
- **定价策略**：输入 $1.25/百万 token，输出 $4.25/百万 token；"贡献者版本"价格更低至 10 倍以上差距
- **差异化亮点**：模型与 Muse Code 同步开发训练；提供"零数据留存"功能，不收集开发者数据训练模型

**值得关注的原因**：Meta 以低价策略正式入局 AI 编程赛道，标志着巨头之间的价格战从模型层延伸到 Agent 产品层。零数据留存功能直击企业客户的隐私痛点，可能吸引对数据安全敏感的团队。"贡献者版本"的低价模式可能改变开发者对编程 Agent 的付费习惯。

## 2. Addy Osmani 开源 agent-skills 仓库，24 小时斩获 82K Star

**类别：AI Coding**

Google Chrome 工程负责人 Addy Osmani 发布 agent-skills 仓库，提供面向 AI 编码 Agent 的生产级工程模式库，涵盖提示工程、代码审查、测试生成、大规模重构等场景。仓库上线 24 小时内获近 82,000 star，创 GitHub AI 工具类仓库历史最快增长纪录。

每个 skill 以模块化、可复用单元形式呈现，可直接集成到现有工作流中，填补了开发者社区对结构化最佳实践的迫切需求。

**值得关注的原因**：这标志着 AI 编码从"惊叹期"进入"专业化期"——开发者不再满足于"能不能用 AI 写代码"，而是追问"如何系统化地用好 AI 编码"。类比敏捷方法对软件工程的意义，agent-skills 可能催生"AI 原生开发方法论"的完整生态。

## 3. 越疆发布全球首款"具身全栖"人形机器人鹿萌（DOBOT LUMO）

**类别：具身智能**

越疆于 8 月 5 日正式亮相全球首款具身全栖人形机器人鹿萌，身高约 1.3 米，依托全栈自研的空弈具身大模型，在 LIBERO 评测中以平均成功率全球第一登顶。

- **核心突破**：多模态情绪感知、三维空间理解与主动行动、自主学习与长期进化
- **全栖定义**：空间全栖（家庭/商场/校园）、角色全栖（生活搭子/运动玩伴/科普伙伴）、能力全栖（视觉+语音+运动）、周期全栖（伴随用户持续迭代）
- **实测表现**：自然拟人步态，可穿梭草地/沙地/鹅卵石；户外陪练打拳含后空翻，居家主动关灯、随音乐卡点跳舞

**值得关注的原因**：这是具身智能从工业/商用场景向消费级家庭场景落地的标志性产品。不同于以往仅能语音交互的静态陪伴机器人，鹿萌将情绪感知与物理行动能力融合，押注千亿级智能陪伴市场。空弈大模型在 LIBERO 基准登顶说明其操作能力达到行业顶尖水准。

## 4. 德塔智能完成近 5 亿元天使轮融资，人形机器人"大脑"成资本焦点

**类别：具身智能**

人形机器人基础模型公司德塔智能（Delta Intelligence）完成近 5 亿元天使轮融资，投资方包括多家上市公司产业方和头部财务投资机构。资金将用于基础模型迭代、自研数采设备量产与数据闭环建设、核心研发团队扩充。这是该公司成立半年内完成的第六轮融资。

同期，蚂蚁灵波启动首轮 15 亿元募资，聚焦通用机器人大脑；求之科技完成 1 亿美元天使+轮。三家同日官宣巨额融资，方向惊人一致——都做机器人的"大脑"。

**值得关注的原因**：资本正从"造身体"转向"造大脑"。上半年国内具身智能融资总额 935 亿元（同比增 5 倍），其中"具身大模型"赛道 40 起、223 亿元，是资金最集中方向。硬件已进入同质化阶段，VLA、世界模型等具身基础模型才是终局壁垒。德塔智能半年六轮的融资速度，反映出"机器人大脑"被资本作为独立资产在定价。

## 5. Anthropic 确认组建内部芯片团队，为 Claude 自研定制芯片

**类别：AI Coding / 基础设施**

据 Business Insider 报道，Anthropic 确认正在招聘工程师，为 Claude AI 模型设计定制芯片，原因是模型需求量急剧攀升。这一动向使其加入 Google（TPU）、Meta（MTIA）、Amazon（Trainium）等自研芯片巨头的行列。

**值得关注的原因**：AI 编程赛道的竞争正在向底层硬件延伸。Anthropic 此前凭借 Claude Code 在编程赛道占据领先位置（SWE-bench Verified 95.0%），自研芯片意味着其将在推理成本和性能上获得更深层控制力。这也预示着 AI Coding Agent 的竞争不再只是模型和产品层面，而是从芯片到应用的全栈较量。
