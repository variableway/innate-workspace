## Agent Kanban Phase 1+2: 双后端 MVP

执行了双后端实现计划的 Phase 1（Go 后端）和 Phase 2（Node.js 后端），两个后端都已编译通过。

### Go 后端 (backend-go/)
技术栈：chi v5 + sqlx + modernc.org/sqlite (纯 Go，无 CGO) + google/uuid + go-chi/cors

文件结构（10 个文件）：
- `cmd/kanban-api/main.go` — 入口，chi 路由 + CORS + slog 日志
- `internal/config/config.go` — 环境变量配置
- `internal/model/models.go` — 数据模型 (Workspace/Project/Task/Agent/Assignment + 组合视图)
- `internal/store/store.go` — SQLite 连接 + 自动迁移（内联 schema）
- `internal/store/crud.go` — 所有 CRUD 操作 + 统计查询
- `internal/handler/handler.go` — 全部 HTTP handler + 路由注册
- `migrations/001_init.up.sql` — = docs/schema.sql
- `migrations/001_init.down.sql` — Drop all tables
- `go.mod` + `Makefile`

验证：`go build -C backend-go ./...` 通过

### Node.js 后端 (backend-node/)
技术栈：Hono + @hono/node-server + better-sqlite3 + TypeScript strict

文件结构（10 个文件）：
- `src/index.ts` — Hono server 入口，注册所有路由 + CORS + logger
- `src/lib/db.ts` — better-sqlite3 单例 + 自动迁移（读 docs/schema.sql）
- `src/routes/workspaces.ts` — Workspace CRUD + Stats
- `src/routes/projects.ts` — Project CRUD + Sync 触发
- `src/routes/tasks.ts` — Task 聚合查询（跨项目）+ 详情
- `src/routes/agents.ts` — Agent CRUD + 详情（含统计）
- `src/routes/assignments.ts` — 手动分配 + 自动分配 (Label Router) + 列表
- `src/routes/webhooks.ts` — GitHub webhook 接收 + 基础 issue 同步
- `package.json` + `tsconfig.json`

验证：`tsc --noEmit` 通过
